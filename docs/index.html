FAQ

Good questions.

Is it really free?

Yes. No premium tier, no ads, no account. It runs on free-tier hosting with Telegram's and Wikipedia's free public APIs.

Do I need to install anything?

No. If you have Telegram, you're done. Open the bot, press Start, type a command.

How does it behave in groups?

Add it like any member. Quizzes become fastest-answer-wins with a shared leaderboard, and ordinary conversation is ignored — the bot never chimes in uninvited.

How do digest times work?

Times are UTC. /digest add physics 08:00 delivers at 8am UTC; /digest time 18:30 moves it. Pause anytime with /digest off.

Which languages are supported?

English Wikipedia today; per-user language preferences are on the roadmap.

Who writes the answers?

Wikipedia contributors. TeleWiki fetches summaries, featured articles and “on this day” events live, and always links back to the source article.
