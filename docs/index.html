FAQ

Good questions.

Is TeleWiki really free?

Yes. No premium tier, no ads, no account. It runs on free-tier infrastructure and free public APIs (Telegram + Wikipedia).

Do I need to install anything?

No. If you have Telegram, you already have everything. Open the bot and type a command.

Can I use it in group chats?

Yes — add the bot to any group. Quizzes become fastest-answer-wins competitions with a shared leaderboard. Plain chatter is ignored so the bot never spams.

How do digest times work?

Times are in UTC. For example, /digest time 08:00 delivers at 8am UTC daily. Pick the hour closest to your morning.

Which languages are supported?

The bot currently reads the English Wikipedia. More language editions are on the roadmap.

Where does the content come from?

Directly from Wikipedia and Wikidata via public APIs. Article text is by Wikipedia contributors, available under CC BY-SA.
